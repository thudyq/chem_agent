# 机理箭头规范：起点 · 去向 · 用途

箭头分两大体系：**电子推动箭头**（描述电子流动）与**辅助箭头**（宏观关系）。电子推动箭头又分**反应机理箭头**与**共振转换箭头**。

---

## 第 0 条：方向规则（最重要）

**弯箭头 = 电子从富电子处流向缺电子处。** 起点永远是**电子供体**（孤对电子、π 键、σ 键、自由基单电子），终点永远是**电子受体**（正离子、空轨道原子、被进攻的键）——**不要写反**。

- 亲电取代：苯环 π 电子 → NO₂⁺ 的 N，写 `ar:0-5>nu:0`（π 键中点在前、试剂在后）
- 亲核取代：OH⁻ 孤对 → 底物碳，写 `nu:0>r0:0`
- 断键：C—Cl 键电子流向离去基团，写 `r0:0-1>r0:1`（起点是 σ 键中点）
- 快速自检：起点一侧必须"有电子可给"；若起点落在缺电子物种（正离子）上，方向多半写反了

## 一、普通反应机理箭头（`>` 双电子）

### 起点（电子供体）

| 起点类型 | MECHARROW 写法 | 适用场景 |
| :--- | :--- | :--- |
| 孤对电子 | `nu:0`（杂原子序号） | 亲核取代（SN2）、酸碱 |
| π 键 | `cc:0-1`（键中点） | 亲电加成、共轭加成 |
| σ 键 | `r0:0-1`（键中点） | 断键、消除、重排 |
| 显式 H 原子 | `rh:1`（H 原子序号，SMILES 写 [H]） | 夺氢/去质子（断键语义） |

### 终点（电子受体）

| 去向 | MECHARROW 写法 | 结果 |
| :--- | :--- | :--- |
| 指向原子 | `r0:0` | 形成 σ 键（亲核进攻） |
| 指向键中点 | `cc:0-1` | 形成 π 键（消除） |
| 指向离去基团 | `lg:0` | 断 σ 键，离去基团带电子对离开 |

### 完整示例

| 机理 | MECHARROW 写法 |
| :--- | :--- |
| 亲核进攻 SN2 | `nu:0>r0:0`（孤对→底物碳）、`r0:0-1>r0:1`（σ 键→离去基团） |
| 亲电加成 | `cc:0-1>hp:0`（π 键→H⁺） |
| 亲电取代（苯环） | `ar:0-1>nu:0`（π 键→亲电试剂） |
| 消除 E1/E2 | β-H 显式写出（如 `CC([H])CCl`），再写 `r0:0-1>r0:1-2`（β C—H σ 键→αβ 键位成 π 键）、`r0:1-2>r0:2`（α C—LG σ 键→离去原子） |

## 二、共振转换箭头（极限式之间）

**核心区别**：普通反应箭头表示实际原子重排；共振箭头只表示**电子的离域重排**——原子核坐标和 σ 键骨架完全不动，只有 π 键和孤对电子流动。

共振箭头用 `[ARROW:type=resonance]`（容器内，共振块 `[BLOCK]` 内自动画方括号），3 种固定模式：

| 模式 | 起点 | 去向 | 实例 |
| :--- | :--- | :--- | :--- |
| 孤对电子 → 相邻 π 键 | 带孤对的原子（O、N） | 相邻原子间的双键 | 烯醇式 → 羰基式 |
| π 键 → 相邻 π 键（共轭传递） | 当前 π 键 | 下一根 π 键 | 1,3-丁二烯电子摆动 |
| π 键 → 相邻原子 | π 键 | 电负性大的端基原子（O、N） | C=O 电子全转移到 O |

共振式通常同时画两个箭头（一个电子离开、一个旧 π 键变孤对），保证电荷守恒。**共振式用 ↔ 或弯箭头，绝不用反应主箭头 →。**

## 三、自由基鱼钩箭头（`>>` 单头）

- 起点：自由基单电子或 σ/π 键中的**一个**电子；去向：另一自由基原子（成键）或离去基团
- **电子守恒（关键）**：每个电子的去向都要画鱼钩——均裂一根键画**两个**鱼钩；三电子转移机理画三个。只画一个让新自由基来源不明，属逻辑错误

| # | 机理 | MECHARROW 写法（id 为组件引用名，原子序号从 0 起） |
| :--- | :--- | :--- |
| 1 | 均裂 X—X → X• + •X | `xx:0-1>>xx:0`、`xx:0-1>>xx:1`（两个都从 σ 键中点出发、各指一个 X） |
| 2 | 加成 X• + C=C | `x:0>>x:0+cc:0`（X• 单电子→成键空白）、`cc:0-1>>x:0+cc:0`（π 键一电子→同空白）、`cc:0-1>>cc:1`（π 键另一电子→远端碳） |
| 3 | 夺氢 X• + H—R | H 显式写出（`C([H])([H])([H])[H]`），再写：`x:0>>x:0+rh:0`、`rh:1>>x:0+rh:0`（H 原子→同空白）、`rh:1>>rh:0`（H→反应物 R 原子） |
| 4 | 夺卤 R• + X—X | `r:0>>r:0+xx:0`、`xx:0-1>>r:0+xx:0`、`xx:0-1>>xx:1` |
| 5 | 消除（α 单电子） | `a:0>>a:0+b:0`、`b:0-1>>a:0+b:0`（形成 C=C）、`b:0-1>>lg:0` |
| 6 | 偶联 X• + •X | `xa:0>>xa:0+xb:0`、`xb:0>>xa:0+xb:0`（钩尖留间隙，成 σ 键） |

**要点**：自由基鱼钩一律 `>>`；**成键鱼钩终点写两原子组合端点 `id:a+id:b`**（新键形成处，钩尖自动留间隙）；只有电子落回原子的鱼钩（生成新自由基、离去基团带走电子）才指向原子。

## 四、辅助大箭头（非电子推动）

| 符号 | 名称 | 含义 |
| :--- | :--- | :--- |
| → / ⟶ | 反应主箭头 | 连接反应物与产物，上方标条件（Heat、H⁺） |
| ⇌ | 平衡箭头 | 可逆反应/酸碱平衡，**不代表电子移动** |
| ↔ | 共振箭头 | 连接同一物质的不同电子表述（共振极限式） |
| + | 加号 | 分隔反应物/产物/副产物 |

## 五、错误示范与黄金法则

常见陷阱：
1. 箭头起始于碳原子本身（碳无孤对，不能作供体起点）
2. 共振式中箭头指向原子核（应指向键或原子外侧）
3. 混淆 ↔ 和 →：共振式绝不用 → 

黄金法则：
- **看骨架**：原子位置变了吗？→ 反应机理箭头；没变只是电子画法变？→ 共振箭头
- **看起点**：尾部必须对着孤对电子、π 键或单电子
- **看终点**：头部指向能接收电子的空轨道（反应）或相邻键/电负性原子（共振）
