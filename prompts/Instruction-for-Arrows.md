# 有机化学机理图中箭头的完整分类（起点·去向·用途）

在有机化学中，箭头分为两大体系：**电子推动箭头**（描述电子流动）和**辅助箭头**（描述过程关系）。其中，电子推动箭头根据应用场景，又可严格区分为 **反应机理箭头** 和 **共振转换箭头**。

---

## 第 0 条：方向规则（最重要，先读这条）

**弯箭头 = 电子从富电子处流向缺电子处。** 写 `[MECHARROW]` 时，起点（src）永远是
**电子供体**（富电子端：孤对电子、π 键、σ 键、自由基单电子），终点（dst）永远是
**电子受体**（缺电子端：正离子、空轨道原子、被进攻的键）——**不要写反**。

- 亲电取代：苯环 π 电子 → NO₂⁺ 的 N 原子，写 `ar:0-1>nu:0`
  （起点是苯环的 π 键中点，组件 ar 在前、NO₂⁺ 组件 nu 在后）。
- 亲核取代：OH⁻ 的孤对电子 → 底物碳，写 `nu:0>r0:0`（亲核试剂在前、底物在后）。
- 断键：C—Cl 键电子对流向离去基团，写 `r0:0-1>r0:1`（起点是 σ 键中点）。
- 快速自检：起点一侧必须"有电子可给"（孤对电子/π 键/σ 键/单电子）；
  若起点落在缺电子物种（正离子、碳正离子）上，方向多半写反了。

## 第一部分：普通反应机理中的电子推动箭头（断键/成键过程）

这类箭头用于描述**实际的化学变化**，即旧共价键的断裂与新共价键的形成，原子核的相对位置会发生改变。

### 1. 箭头的起始点（电子供体）

| 起始类型             | 图示说明                                                | 适用场景                                  |
| :------------------- | :------------------------------------------------------ | :---------------------------------------- |
| **孤对电子**         | 箭头从杂原子（O、N、X）或碳负离子上的一对孤对电子发出。 | 亲核取代（SN2）、酸碱反应。               |
| **π 键**             | 箭头从双键或三键的电子云中间（两根杠之间）发出。        | 亲电加成、共轭加成。                      |
| **σ 键**             | 箭头从单键的键轴中间发出。                              | 周环反应、σ-迁移重排（如 1,2-烷基迁移）。 |
| **单电子（自由基）** | 使用**鱼钩箭头（单箭头）**，起点为单个未成对电子。      | 自由基卤代、自由基聚合引发。              |

### 2. 箭头的去向（电子受体 / 结果）

| 去向类型             | 指向位置                                               | 结果                                                         |
| :------------------- | :----------------------------------------------------- | :----------------------------------------------------------- |
| **指向特定原子**     | 箭头直接指向缺电子原子（碳正离子、硼原子等）的核附近。 | 形成新的 σ 键（亲核进攻）。                                  |
| **指向两个原子之间** | 箭头指向相邻两个原子连线的中间（键轴方向）。           | 形成新的 π 键（常见于消除反应 E1/E2）。                      |
| **指向离去基团**     | 箭头从 σ 键指向离去基团（如 Br⁻, OTs⁻）的原子。        | 断裂旧 σ 键，离去基团带着一对电子离开。                      |
| **指向共轭链末端**   | 箭头在共轭体系中连续指向下一根键或原子。               | 电子离域，使电荷在共轭链末端分布（α,β-不饱和羰基的 1,4-加成）。 |

## 第二部分：共振结构（极限式）之间的转换弯箭头

> **核心区别**：普通反应箭头表示“实际的原子重排和化学变化”，而共振转换箭头仅表示 **“电子的离域重排”**。

### 特别声明（避坑指南）
在共振极限式之间转换时，**原子核的坐标和σ键骨架（单键框架）完全不动**。只有 **π 键** 和 **孤对电子** 发生“流动”来重新分配电荷。因此，这类箭头严格来说只是纸上“推电子”的思维工具，**不涉及真正断键后生成新异构体**。

### 共振转换箭头的 3 种固定模式

| 转换模式                            | 箭头的起点                            | 箭头的去向                                            | 经典实例                                                     |
| :---------------------------------- | :------------------------------------ | :---------------------------------------------------- | :----------------------------------------------------------- |
| **孤对电子 → 相邻 π 键**            | 从带有孤对电子的原子（如 O、N）发出。 | 箭头指向该原子**与相邻原子之间的 π 键**（双键位置）。 | 烯醇式结构 → 羰基式（-O-H 变成 C=O）。                       |
| **π 键 → 相邻 π 键（共轭链传递）**  | 从当前 π 键的电子云发出。             | 箭头指向下一根相邻的 π 键（或双键位置）。             | 1,3-丁二烯中电子在 C1-C2 和 C3-C4 之间的来回摆动。           |
| **π 键 → 相邻原子（形成孤对电子）** | 从 π 键发出。                         | 箭头指向 π 键端基的**电负性较大的原子**（如 O、N）。  | 丙酮中 C=O 的双键电子完全转移到 O 原子上，使 O 带负电荷（形成氧负离子）。 |

> **注意**：在画共振式时，通常使用 **弯箭头（Curly Arrows）**，且常常需要同时画出**两个箭头**（一个表示电子离开去形成新 π 键，另一个表示旧的 π 键断裂变成孤对电子），以确保整个分子的电荷守恒。

## 第三部分：特殊电子——单电子（鱼钩箭头）

专门用于自由基机理，与上述双电子弯箭头（↷）并列。

- **起点**：单个未成对电子（自由基中心）或 σ 键/π 键中的**一个**电子。
- **去向**：指向另一个自由基的原子（成键），或指向离去基团（断键后留下一个单电子）。
- **图示**：使用 **单头鱼钩箭头（⇀）**，而非双头弯箭头（↷）。
- **电子守恒（关键）**：每个电子的去向都必须画出鱼钩。一根 σ/π 键均裂时两个
  电子各走一个方向，因此断一根键通常要画**两个鱼钩**分别指出两个去处；
  只画其中一个会让新自由基的来源不明，属于逻辑错误。

### 六种常见自由基机理的鱼钩写法（直接套用）

| # | 机理 | 通式 | MECHARROW 写法（id 为组件引用名，原子序号从 0 起） |
| :-- | :-- | :-- | :-- |
| 1 | **均裂** | X—X → X• + •X（Δ 或 hv） | 两个 `>>` 都从 σ 键中点出发、各指向一个 X 原子：`xx:0-1>>xa:0`、`xx:0-1>>xb:0`（一左一右分开，每个原子各得一个电子） |
| 2 | **加成到 π 键** | X• + C=C → X—C—C• | 三个 `>>`：`x:0>>x:0+cc:0`（X• 单电子→成键空白位）、`cc:0-1>>x:0+cc:0`（π 键一个电子→同一空白位）、`cc:0-1>>cc:1`（π 键另一电子→远端碳，生成新自由基） |
| 3 | **夺氢** | X• + H—R → X—H + •R | 需先 `[XH:rh\|H序号]` 写出 H，再写三个 `>>`：`x:0>>x:0+rh:0#k`（X•→X 与 H 之间空白位）、`rh:0#k>>x:0+rh:0#k`（H—R σ 键→同一空白位）、`rh:0#k>>rh:0`（H—R σ 键→R 原子，剩单电子）。转移的是整个氢原子 H•，勿与质子转移（只移 H⁺）混淆 |
| 4 | **夺卤** | R• + X—X → R—X + •X | 同夺氢，被夺的是卤原子：`r:0>>r:0+xx:0`、`xx:0-1>>r:0+xx:0`、`xx:0-1>>xx:1` |
| 5 | **消除** | 带单电子的 α 位、相邻 β 位 | 三个 `>>`：`a:0>>a:0+b:0`（α 位单电子→αβ 键空白位）、`b:0-1>>a:0+b:0`（β 位 σ 键→同一空白位，形成 C=C）、`b:0-1>>lg:0`（β 位 σ 键→离去基团，其带走一个电子成为自由基） |
| 6 | **偶联** | X• + •X → X—X | 两个 `>>` 分别从两个 X• 的单电子出发、指向两原子之间的空白成键位：`xa:0>>xa:0+xb:0`、`xb:0>>xa:0+xb:0`（钩尖留小间隙，结合成 σ 键） |

> **绘制要点**：自由基鱼钩一律用 `>>`（单头）；**成键鱼钩终点不写原子**，写两原子组合端点 `id:a+id:b`（新键形成处，钩尖自动留小间隙）；只有电子落回原子的鱼钩（生成新自由基、离去基团带走电子）才指向原子。**每个电子的去向都必须画全**——断一根键通常要两个鱼钩（均裂/偶联），三电子转移机理通常三个（加成/夺氢/夺卤/消除），只画一个会让新自由基来源不明，属于逻辑错误。

## 第四部分：辅助性大箭头（非电子推动）

这些箭头不表示电子流动，仅用于宏观逻辑连接，请注意区分。

| 箭头符号       | 名称       | 功能与含义                                                   |
| :------------- | :--------- | :----------------------------------------------------------- |
| **→** 或 **⟶** | 反应主箭头 | 连接反应物和产物，表示反应进行的宏观方向。上方常标注反应条件（如 Heat, H⁺）。 |
| **⇌**          | 平衡箭头   | 表示可逆反应或酸碱平衡（质子转移），**不代表电子移动**。     |
| **↔**          | 共振箭头   | **专门**用于连接两个或以上的共振极限式（如苯的两种凯库勒结构）。它与“反应主箭头”有本质区别：↔ 两边是**同一物质的不同电子表述**，而非不同物质。 |
| **+**          | 加号       | 分隔反应物、产物或副产物。                                   |

## 第五部分：错误示范与黄金法则

### 常见的画图陷阱（错误起点/去向）

1.  **箭头起始于碳原子本身**（而非孤对电子或键）：碳如果没有孤对电子，不能作为电子供体起点。
2.  **共振式中箭头指向了原子核**：在共振式中，箭头应指向**键或原子外侧**（表示形成孤对电子或 π 键），而在普通反应中箭头才指向原子核（形成 σ 键）。
3.  **混淆 ↔ 和 →**：在写共振式时，绝不能用反应主箭头（→），只能用共振箭头（↔）或双头箭头（⟷）。

### 总结黄金法则

- **看骨架**：原子位置变动了吗？→ 是反应机理箭头；原子位置没变，只是电子画法变了？→ 是共振转换箭头。
- **看起点**：尾部必须对着孤对电子、π键或单电子（不能对着真空或饱和碳原子）。
- **看终点**：头部必须指向能接收电子的空轨道（反应）或指向相邻的键/电负性原子（共振）。

## 第六部分：渲染标记中机理箭头的书写要点

在 `[COMPOSITE]` 容器内用 `[MECHARROW]` 画弯箭头（`>>` 为鱼钩箭头）。**起点写法决定箭头类型**，方向、弯向、孤对电子点均由渲染器自动处理，你只需写对起点和终点：

1. **进攻箭头**：起点写电子供体的**杂原子序号**（如 `nu:0>r0:0`，亲核试剂在前、底物在后）。渲染器自动从该原子的孤对电子点出发、向上弯向目标。
2. **断键箭头**：起点必须写**键中点** `a-b`（如 `r0:0-1>r0:1`，C(0)-Cl(1) 键电子流向 Cl(1)），或显式 H `a#k`（需先 [XH] 画出）——**不要写从单个原子出发**，否则会按进攻箭头绘制。
3. **终点**：写接收电子的原子序号（箭头尖自动落在该原子上）；消除成 π 键时可写键中点。**成键鱼钩终点不写原子**，写两原子组合端点 `id:a+id:b`（新键形成处，可跨组件）。
4. **COMPOSITE 中用 id 引用组件**：给参与电子转移的 STRUCT 起有意义的 id（如 `id=nu` 亲核试剂、`id=lg` 离去基团），MECHARROW 引用更清晰；未命名的组件按出现顺序自动编号 r0/r1/...。
