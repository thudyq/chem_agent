# SMILES 书写规范

## 一、基本规则

- 原子按连接顺序写出符号（C、O、N、Cl…）；**氢默认不写**，由价态自动补全。
- 相邻两个原子之间默认是单键；双键写 `=`，三键写 `#`。
- 支链用括号 `()`，环用数字配对，电荷/自由基/显式氢用方括号 `[]`——见下文。

**例：乙醇** 结构式 CH₃—CH₂—OH → SMILES `CCO`（两个碳连单键 CC，氧接第二个碳 O，H 全省略）。

## 二、基础写法

### 2.1 碳链与常见分子

| 分子 | SMILES | 分子 | SMILES |
| :--- | :--- | :--- | :--- |
| 甲烷 | `C` | 乙醇 | `CCO` |
| 乙烷 | `CC` | 乙醚 | `CCOCC` |
| 丙烷 | `CCC` | 二甲胺 | `CNC` |
| 氯乙烷 | `CCCl` | 乙醛 | `CC=O` |
| 乙烯 | `C=C` | 丙酮 | `CC(=O)C` |
| 乙炔 | `C#C` | 乙酸 | `CC(=O)O` |
| 2-丙醇 | `CC(O)C` | 叔丁醇 | `CC(C)(C)O` |

**规则**：碳链是 C 的连续串；`=`/`#` 写在原子之间。**羰基必须写 `=O`**（写 CO 是醇）；括号挂在括号前那个原子上（`CC(=O)O` = 第二个 C 连 `=O` 和 `O`）。

### 2.2 官能团速查

| 官能团 | SMILES | 官能团 | SMILES |
| :--- | :--- | :--- | :--- |
| 醇 R–OH | `CCO` | 醚 R–O–R' | `CCOCC` |
| 醛 R–CHO | `CC=O` | 胺 R–NH₂ | `CN` |
| 酮 R–CO–R' | `CC(=O)C` | 硝基 R–NO₂ | `O=[N+]([O-])C` |
| 羧酸 R–COOH | `CC(=O)O` | 酯 R–COO–R' | `CC(=O)OC` |

## 三、环：数字配对

数字表示"与相同数字的原子成环"：环己烷 `C1CCCCC1`（1 号出发走 5 个碳闭合）、环丙烷 `C1CC1`。

**苯环写法按场景区分**：静态结构、键特征、芳香性讨论用芳香小写 `c1ccccc1`（画圆圈式）；反应、机理中用凯库勒大写式 `C1=CC=CC=C1`（环键按普通单双键引用）。同一反应/机理内所有苯环的凯库勒式必须相同（双键位置一致），除非有意表示共振。

## 四、方括号 `[]`：电荷、自由基、显式氢

**规则：任何带电/自由基/特殊状态原子必须用方括号**。裸写 `OH-`、`NH4+` 非法。

| 物种 | 正确 | 错误 |
| :--- | :--- | :--- |
| 质子 | `[H+]` | `H+` |
| 氢自由基 | `[H]` | `H` |
| 氢氧根 | `[OH-]` | `OH-` |
| 水合氢离子 | `[OH3+]` | `H3O+` |
| 铵根 | `[NH4+]` | `NH4+` |
| 甲基自由基/负离子 | `[CH3]`/`[CH3-]` | `CH3`/`CH3-` |
| 氯离子 | `[Cl-]` | `Cl-` |

电荷 `+`/`-` 在方括号末尾；二价 `+2`/`-2`。

### 4.1 显式氢 `[H]`

SMILES 中写 `[H]` 就是真实氢原子，与其他原子一样按出现顺序参与编号（0 起）：

| 场景 | SMILES | 原子编号 |
| :--- | :--- | :--- |
| 甲烷（全显式） | `C([H])([H])([H])[H]` | 0=C、1~4=H |
| 乙醛 α-H 显式 | `C([H])C=O` | 0=C、1=H、2=C(=O)、3=O |
| 水（全显式） | `O([H])[H]` | 0=O、1~2=H |
| 氨（全显式） | `N([H])([H])[H]` | 0=N、1~3=H |

## 五、无机物与金属盐

反应式中的无机物有两种写法（双轨制）：**教科书化学式直写**（KMnO4、H2SO4、H2O、O2、CaCO3 等，渲染为带下标的文本）或合法 SMILES。化学式写法最省事，但化学式组件没有原子结构——不能参与机理箭头、氢键、电荷/键标注（要参与这些必须写 SMILES）。不参与主反应的辅助试剂（催化剂、溶剂等）写在箭头条件里，不必画结构。

金属阳离子与酸根之间没有共价键——写成独立离子用 `.` 分隔。**不要写 `KMn(=O)=O` 这类直接连键形式**（非法）。

| 物质 | 离子式 SMILES |
| :--- | :--- |
| 高锰酸钾 | `[K+].[O-][Mn](=O)(=O)=O` |
| 重铬酸钾 | `[K+].[K+].[O-][Cr](=O)(=O)O[Cr](=O)(=O)[O-]` |
| 氯酸钾 | `[K+].[O-][Cl](=O)=O` |
| 碳酸钠 | `[Na+].[Na+].[O-]C(=O)[O-]` |
| 氯化钠 | `[Na+].[Cl-]` |

含氧酸根：高锰酸根 `[O-][Mn](=O)(=O)=O`、重铬酸根 `[O-][Cr](=O)(=O)O[Cr](=O)(=O)[O-]`、氯酸根 `[O-][Cl](=O)=O`、碳酸根 `[O-]C(=O)[O-]`、硫酸分子 `OS(=O)(=O)O`、硫酸氢根 `OS(=O)(=O)[O-]`、硝酸根 `[O-][N+](=O)O`、磷酸分子 `OP(=O)(O)O`。**注意：负电荷在氧上，不在中心原子上**（硫酸氢根写 `O[S-](=O)(=O)O` 非法——S 不能带负电还连 4 个氧）。

## 六、配位化合物

配离子与无机物相同，直接写分子式：`[Ag(NH3)2]+`、`[Cu(NH3)4]2+`、`[Fe(CN)6]3-`——方括号内"中心原子+(配体)系数"+尾部电荷；带反离子的中性配合物同样直写（`[Ag(NH3)2]OH`、`K4[Fe(CN)6]`）；配体括号必须写全（`[AgNH3]+` 非法）。

需要画出配位结构时写 SMILES，配体作为分支挂在中心金属上：

| 络离子 | SMILES |
| :--- | :--- |
| 银氨络离子 | `[Ag+]([NH3])([NH3])` |
| 铜氨络离子 | `[Cu+2]([NH3])([NH3])([NH3])([NH3])` |

**关键陷阱**：`NH3` 裸写非法（写 `[NH3]` 或 `N`）；中性配体（NH₃、H₂O、CO）不单独带电；Cl⁻ 等**阴离子配体写不成键连 SMILES**（RDKit 价态拒绝）——四氯合铂(II) 用分子式 `[Pt(Cl)4]2-`，不要写 `[Pt+2](Cl)(Cl)(Cl)(Cl)`（电荷错成 +2）。

## 七、机理中间体

### 7.1 基础中间体

| 场景 | SMILES | 说明 |
| :--- | :--- | :--- |
| 碳负/正离子 | `[CH3-]`、`[CH2-]C=O`、`[CH3+]` | 烯醇负离子/碳正离子 |
| 质子化 | `CC[OH2+]`、`CC[OH+]CC` | 质子化醇/醚 |
| 自由基 | `[CH3]`、`[Cl]` | 单电子不写电荷 |
| 烷氧负离子 | `[O-]C`、`[O-]CC` | 醇去质子 |

### 7.2 质子化羰基与环鎓离子

- 质子化乙醛 `CC=[OH+]`（氧 2 键带 +1）；质子化丙酮 `CC(C)=[OH+]`；质子化羧酸 `CC(=O)[OH2+]`
- 溴鎓 `[Br+]1CC1`、质子化环氧化物 `[OH+]1CC1`、硫鎓 `[S+]1CC1`、环氧化物 `C1CO1`——杂原子带正电荷后可成 2~3 环键

### 7.3 σ 络合物（Wheland 中间体，芳香亲电取代）

苯环 6 个碳之一变 sp³、连亲电试剂 E，与之双键相连的碳变 `[CH+]`，双键变单键，环数字闭合：

| 场景 | SMILES |
| :--- | :--- |
| 苯硝化 σ 络合物 | `O=[N+]([O-])C1C=CC=C[CH+]1` |
| 苯溴代 σ 络合物 | `BrC1C=CC=C[CH+]1` |
| 苯质子化 σ 络合物 | `C1C=CC=C[CH+]1` |

机理中要在 sp³ 碳上引用氢时，把它写成显式 H：`O=[N+]([O-])C([H])1C=CC=C[CH+]1`（见 §4.1）。

### 7.4 其他常见中间体

叔丁基正离子 `C[C+](C)C`、烯丙基正/负离子 `C=C[CH2+]`/`C=C[CH2-]`、苯甲酰正离子 `O=[C+]c1ccccc1`、卡宾 `[CH2]`。

### 7.5 常见错误

- `C[OH2+]` ≠ `CC[OH2+]`（质子化甲醇 vs 乙醇——写 label 前数清碳链）
- 质子化羰基氧写 `C=[OH+]`（2 键）而非 `C=[OH2+]`（3 键超价态）
- 溴鎓写 `Br1CC1` 非法——Br 必须带 +1：`[Br+]1CC1`
- σ 络合物漏环闭合数字或把 sp³ 碳写成双键——环上必有一个 `[CH]`/`[CH+]` 挂亲电试剂
- 价态底线：C≤4、N≤4、O≤2（鎓离子带正电后可 3）、卤素≤1（鎓离子除外）

## 八、写完后自检清单

1. **电荷都在 `[...]` 内**——裸写 `OH-`/`NH4+` 非法；
2. **金属盐用 `.` 分隔**，未与酸根直接连键；
3. **环数字配对、括号平衡**；
4. **价态自检**：C≤4、N≤4、O≤2、卤素≤1。
