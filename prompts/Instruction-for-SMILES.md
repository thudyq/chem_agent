# SMILES 书写规范

SMILES 是**结构式的一维线性编码**：每个原子一个符号，按连接顺序写下来。渲染器会把 SMILES 还原成结构式，所以**写错了画出来就是错的**。本规范教你从零写对 SMILES。

---

## 一、心智模型：SMILES = 沿着化学键走一遍分子

写 SMILES 前，先在脑中画出（或想象）分子的键线式，然后**从一个原子出发，沿键序把原子符号写下来**：

- 原子符号直接写（C、O、N、Cl…），**氢永远不写**——氢由价态自动补全
- 键不写符号，**相邻两个符号就是一根单键**
- 双键写 `=`，三键写 `#`
- 支链、环、电荷需要括号 `()` 和数字——见下文

**例：乙醇**
```
结构式：CH₃—CH₂—OH
SMILES：C C O   →   CCO
```
两个碳连一根键（CC），氧连在第二个碳上（O）。H 全部省略。

## 二、基础：简单有机物（写对 90% 的分子）

### 2.1 碳链 = 一连串 C

| 分子 | 结构 | SMILES |
| :--- | :--- | :--- |
| 甲烷 | CH₄ | `C` |
| 乙烷 | CH₃CH₃ | `CC` |
| 丙烷 | CH₃CH₂CH₃ | `CCC` |
| 丁烷 | CH₃CH₂CH₂CH₃ | `CCCC` |
| 氯乙烷 | CH₃CH₂Cl | `CCCl` |
| 乙醇 | CH₃CH₂OH | `CCO` |
| 乙醚 | CH₃CH₂OCH₂CH₃ | `CCOCC` |
| 二甲胺 | (CH₃)₂NH | `CNC` |

**规则**：碳链就是 C 的连续串；杂原子（O/N/Cl 等）接在链的对应位置。

### 2.2 双键和三键

| 分子 | 结构 | SMILES |
| :--- | :--- | :--- |
| 乙烯 | CH₂=CH₂ | `C=C` |
| 乙醛 | CH₃CHO | `CC=O` |
| 丙酮 | CH₃COCH₃ | `CC(=O)C` |
| 氢氰酸 | HCN | `C#N` |
| 乙炔 | HC≡CH | `C#C` |

**规则**：`=` 双键、`#` 三键，写在两个原子符号之间。**羰基（C=O）必须写 `=O`**，写 `CO` 就成了醇。

### 2.3 分支：括号 `()`

括号表示"**挂在括号前那个原子上的支链**"。

| 分子 | 结构 | SMILES |
| :--- | :--- | :--- |
| 异丁烷 | (CH₃)₂CHCH₃ | `CC(C)C` |
| 乙酸 | CH₃COOH | `CC(=O)O` |
| 丙酮 | CH₃COCH₃ | `CC(=O)C` |
| 2-丙醇 | (CH₃)₂CHOH | `CC(O)C` |
| 叔丁醇 | (CH₃)₃COH | `CC(C)(C)O` |

**规则**：括号里的内容接在**括号前一个原子**上。`CC(=O)O` = 第二个 C 上连着 `=O` 和 `O`。

### 2.4 常见官能团速查

| 官能团 | 结构式 | SMILES |
| :--- | :--- | :--- |
| 醇 | R–OH | `CCO`（乙醇）、`CC(C)O`（异丙醇） |
| 醛 | R–CHO | `CC=O`（乙醛） |
| 酮 | R–CO–R' | `CC(=O)C`（丙酮） |
| 羧酸 | R–COOH | `CC(=O)O`（乙酸） |
| 酯 | R–COO–R' | `CC(=O)OC`（乙酸甲酯） |
| 醚 | R–O–R' | `CCOCC`（乙醚） |
| 胺 | R–NH₂ | `CN`（甲胺） |
| 硝基 | R–NO₂ | `O=[N+]([O-])C`（硝基甲烷） |

## 三、环：数字配对

数字表示"**与相同数字的原子成环**"。

| 分子 | SMILES | 说明 |
| :--- | :--- | :--- |
| 环己烷 | `C1CCCCC1` | 从 1 号碳出发走 5 个碳回到 1 号 |
| 苯 | `c1ccccc1` | 芳香碳用小写 `c` |
| 环丙烷 | `C1CC1` | 三元环 |

**规则**：开环数字与闭环数字成对。**苯用 `c1ccccc1`**（芳香碳小写），`C1=CC=CC=C1`是 Kekulé 写法，也可用但苯环推荐小写。

---

## 四、方括号 `[]`：电荷、自由基、显式氢、同位素

**规则：任何带电/自由基/特殊状态的原子，必须用方括号包住**。裸写 `OH-`、`NH4+` 是非法 SMILES。

| 物种 | 正确 SMILES | 错误写法 |
| :--- | :--- | :--- |
| 质子 | `[H+]` | `H+` |
| 氢自由基 | `[H]` | `H` |
| 氢负离子 | `[H-]` | `H-` |
| 氢氧根 | `[OH-]` | `OH`、`OH-` |
| 水合氢离子 | `[OH2+]` | `H3O+` |
| 铵根 | `[NH4+]` | `NH4+` |
| 甲基自由基 | `[CH3]` | `CH3` |
| 甲基负离子 | `[CH3-]` | `CH3-` |
| 氯离子 | `[Cl-]` | `Cl-` |

**电荷写法**：`+`/`-` 在方括号末尾。二价用 `+2`/`-2` 或 `++`/`--`（如 `[Ca+2]`、`[O-2]`）。

---

## 五、无机盐：金属与酸根不连键，用 `.` 分隔

**核心规则：金属阳离子与含氧酸根之间没有共价键**——写成两个独立离子，用 `.` 分隔。**绝不要写 `KMn(=O)=O` 这类"把化学式原子直接连键"的形式**（RDKit 判非法）。

| 物质 | 正确 SMILES | 错误写法 |
| :--- | :--- | :--- |
| 高锰酸钾 | `[K+].[O-][Mn](=O)(=O)=O` | `KMn(=O)=O`、`KMnO4` |
| 重铬酸钾 | `[K+].[K+].[O-][Cr](=O)(=O)O[Cr](=O)(=O)[O-]` | `K2Cr2O7` |
| 氯酸钾 | `[K+].[O-][Cl](=O)=O` | `KClO3` |
| 碳酸钠 | `[Na+].[Na+].[O-]C(=O)[O-]` | `Na2CO3` |
| 氯化钠 | `[Na+].[Cl-]` | `NaCl` |

**通用方法**：阳离子 `[K+]`/`[Na+]` 与阴离子各自独立，用 `.` 连接。

### 含氧酸根速查

| 酸根 | SMILES |
| :--- | :--- |
| 高锰酸根 | `[O-][Mn](=O)(=O)=O` |
| 重铬酸根 | `[O-][Cr](=O)(=O)O[Cr](=O)(=O)[O-]` |
| 氯酸根 | `[O-][Cl](=O)=O` |
| 碳酸根 | `[O-]C(=O)[O-]` |
| 硫酸（分子） | `OS(=O)(=O)O` |
| 硝酸根 | `[O-][N+](=O)O` |
| 磷酸（分子） | `OP(=O)(O)O` |

## 六、配位化合物（络合物）

**核心规则：配位键没有方向，配体作为分支挂在中心金属上**。金属与配体之间不写键符号，直接相邻。

| 络离子 | 正确 SMILES |
| :--- | :--- |
| 银氨络离子 | `[Ag+]([NH3])([NH3])` |
| 铜氨络离子 | `[Cu+2]([NH3])([NH3])([NH3])([NH3])` |
| 四氯合铂(II) | `[Pt+2](Cl)(Cl)(Cl)(Cl)` |

**关键陷阱**：
- **`[Ag(NH3)2]OH` 非法**——方括号内只能是一个原子 + 分支，不能放"完整化学式"
- **`NH3` 裸写非法**——氨必须写 `[NH3]`（N 上的 H 要显式括号）或简化成 `N`
- 银氨整体：银 `[Ag+]`、氨 `[NH3]`、氢氧根 `[OH-]`，各写各的
- **配体电荷**：中性配体（NH₃、Cl 等）不单独带电——四氯合铂(II) 写 `[Pt+2](Cl)(Cl)(Cl)(Cl)`（氯写 `Cl` 而非 `[Cl-]`，否则氯连 2 个键超价态）；电荷集中体现在中心金属上

**写法步骤**：①中心金属（带电荷）；②每个配体一个括号挂在后面；③配体内部照常写。

## 七、机理中间体：价态、电荷、自由基、环鎓

中间体 = 骨架 + 显式电荷/自由基/环结构。**写完后用原子守恒自检**：反应物总原子数 = 产物总原子数（碳数必等，H/O 尽量等）。

### 7.1 基础中间体

| 场景 | 示例 SMILES | 说明 |
| :--- | :--- | :--- |
| 碳负离子 | `[CH3-]`、`[CH2-]C=O` | 烯醇负离子：负电荷碳 |
| 碳正离子 | `[CH3+]`、`[CH2+]C` | 碳正离子 |
| 氧鎓离子（质子化） | `[OH2+]`、`CC[OH2+]` | 质子化水/醇 |
| 质子化醚 | `CC[OH+]CC` | 醚氧质子化 |
| 自由基 | `[CH3]`、`[Cl]` | 单电子不写电荷 |
| 烷氧负离子 | `[O-]C`、`[O-]CC` | 醇去质子 |

### 7.2 质子化羰基（亲电试剂生成）

羰基氧被质子化后带正电荷，C=O 变 `C=[OH+]`（氧仍 2 键、带 +1）：

| 场景 | 示例 SMILES |
| :--- | :--- |
| 质子化乙醛 | `CC=[OH+]` |
| 质子化丙酮 | `CC(C)=[OH+]` |
| 质子化羧酸 | `CC(=O)[OH2+]` |

### 7.3 环鎓离子（环状正离子中间体）

溴鎓/环氧/硫鎓：**杂原子带正电荷后允许成 2~3 个环键**（未带电时卤素只许 1 键、O 只许 2 键）。

| 场景 | 示例 SMILES | 说明 |
| :--- | :--- | :--- |
| 溴鎓离子 | `[Br+]1CC1` | Br 带 +1，三员环（溴对烯烃加成中间体） |
| 质子化环氧化物 | `[OH+]1CC1` | 环氧开环中间体 |
| 硫鎓离子 | `[S+]1CC1` | 硫叶立德前体 |
| 环氧化物（中性） | `C1CO1` | 环氧乙烷 |

### 7.4 σ 络合物（Wheland 中间体，芳香亲电取代）

**写法**：苯环 6 个碳之一变为 sp³ `[CH]`（或 `[CH+]`），该碳连亲电试剂 E，其余 5 碳保留双键交替，环数字配对闭合：

| 场景 | 示例 SMILES | 说明 |
| :--- | :--- | :--- |
| 苯硝化 σ 络合物 | `O=[N+]([O-])[CH]1C=CC=CC1` | NO₂⁺ 加成到环，C1 变 CH（sp³）连 NO₂ |
| 苯溴代 σ 络合物 | `Br[CH]1C=CC=CC1` | Br 加成到环 |
| 苯质子化 σ 络合物 | `[CH+]1C=CC=CC1` | H⁺ 加成，C1 带正电荷 |

**验证方法**：数环上原子——6 个碳必须都在（1 个 sp³ CH 或 CH⁺ + 5 个 sp² 交替双键），亲电试剂挂在 sp³ 碳上。写完后原子守恒检查（反应物芳香环 6C + 亲电试剂 = 产物 6C + E）。

### 7.5 其他常见中间体

| 场景 | 示例 SMILES | 说明 |
| :--- | :--- | :--- |
| 叔丁基正离子 | `CC(C)[C+]` | 重排产物 |
| 烯丙基正离子 | `C=[C+]C` | 共轭稳定 |
| 苯甲酰正离子 | `O=[C+]c1ccccc1` | Friedel-Crafts 酰化 |
| 卡宾 | `[CH2]` | 二价碳 |

### 7.6 常见错误

- `C[OH2+]` ≠ `CC[OH2+]`——前者少一个碳（质子化甲醇 vs 乙醇），写 label 前数清碳链；
- 羰基氧被质子化写 `C=[OH+]`（2 键）而非 `C=[OH2+]`（3 键，超价态）；
- 溴鎓写 `Br1CC1` 非法——Br 必须带 +1：`[Br+]1CC1`；
- σ 络合物漏写环闭合数字或把 sp³ 碳写成双键——环上必有一个 `[CH]`/`[CH+]` 挂亲电试剂；
- 价态合法底线：C ≤ 4 键、N ≤ 4 键、O ≤ 2 键（鎓离子除外，带正电后可 3 键）、卤素 ≤ 1 键（鎓离子除外）。

## 八、写完后自检清单

1. **电荷都在 `[...]` 内**——裸写 `OH-`/`NH4+` 非法；
2. **金属盐用 `.` 分隔**，未与酸根直接连键；
3. **环数字配对、括号平衡**；
4. **数重原子（0 起）**——核对 MECHARROW/XH 的原子序号（H 不占序号）；
5. **价态自检**：C≤4、N≤4、O≤2、卤素≤1。
