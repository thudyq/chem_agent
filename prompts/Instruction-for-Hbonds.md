# 氢键绘制规范（2026-08-15 更新：语义分离）

氢键形成于 `X—H···Y` 三原子体系：

- **共价键 X—H 用实线绘制** —— 由 `[XH]` 标记负责：先 `[XH:组件|原子序号]` 把给体原子的 H 显式画出；
- **氢键 H···Y 用点状虚线绘制**（3~10 个点，teal 圆点）—— 由 `[HBOND]` 标记负责，只画点、不画氢。

## 标记语法（仅容器内，分子内/分子间统一）

```
[HBOND:供体组件:原子#第k个H>受体组件:原子]
```

- `原子#k` 引用给体组件上第 k 个显式 H（必须先 `[XH:供体组件|原子]` 画出，与 MECHARROW 的 a#k 规则一致）；
- 受体为另一组件（或同一组件）的原子序号；
- 分子内氢键：供体/受体组件写同一 id（如 `HBOND:diol:0#1>diol:3`）。

示例（乙二醇分子内）：容器内写

```
[XH:diol|0]
[HBOND:diol:0#1>diol:3]
```

示例（乙酸二聚体分子间）：

```
[STRUCT:CC(=O)O,id=a]
[STRUCT:CC(=O)O,id=b]
[XH:a|3]
[HBOND:a:3#1>b:2]
```

注意：HBOND 已从顶层标记移除，只能写在 `[COMPOSITE]` 容器内。
