# 结构式使用规范

核心原则：**表示法服务于想表达的内容**，不要为画结构而画结构。

## 一、表示法选择

| 表示法 | 适用场景 |
| :--- | :--- |
| 结构式（展开式） | 需要看清每个原子和价键，尤其反应位点周围环境 |
| 结构简式 | 快速表示简单有机物的组成与官能团（CH₃Cl、CH₃CH₂OH） |
| 键线式 | 展示碳骨架与环系，最通用的专业语言；端点/折点默认是碳 |
| Lewis 结构式 | 展示孤对电子、形式电荷、电子来源（`[STRUCT:O, mode=lewis]`） |
| 楔式/Newman/椅式 | 表达立体化学、构象、手性（`mode=stereo/chair/newman`） |
| 基团缩写 | 聚焦核心反应位点，省略非反应部分（R、Ar、X、Ph） |

## 二、简明规则

### 1. 简单分子不必画键线式

CH₃Cl、CH₃OH 等直接写结构简式即可；键线式用于碳骨架、环系、多官能团分子。
**例外**：机理场景（COMPOSITE 容器内）参与电子转移的分子必须画出（机理箭头要锚定原子位置），分子按结构简式绘制。

### 2. 机理中的孤对电子由渲染器自动画

机理场景中参与电子转移的原子的孤对电子点**自动画出**（有弯箭头引用即触发），你只需在 MECHARROW 中写对起点。讨论酸碱/亲核性等需要完整电子式时用 `mode=lewis` 单独展示。

### 3. 反应位点必须突出

- 参与反应的键必须画出来，不能省略或用缩写掩盖
- 反应中心原子必须清晰可见
- **显式画出指定键/标注**：用 STRUCT 参数——`bond=a-b` 红粗线突出、`charge=原子号:+/-` 部分电荷（顶层单分子或容器内均可用）
- **键线式保持**：带标注的 COMPOSITE 组件按键线式绘制——碳不展开 CH₂/CH₃，仅显示杂原子标签与显式画出的 H，标注键红粗线与原键完全对齐

**示例**：丙醛 α-H 与 αβ 键突出 → `[COMPOSITE:row][STRUCT:CCC=O,id=pr,bond=1-2,charge=0:+][/COMPOSITE]`

### 4. 聚焦关键位点，省略非反应部分

分子很大、反应只在局部时，用缩写 R/Ar/X 或波浪线 ~ 表示未反应部分。

**常用缩写**：R 烷基、Ar 芳基、X 卤素、Me 甲基、Et 乙基、Ph 苯基、Ac 乙酰基、Ts 对甲苯磺酰基、Boc 叔丁氧羰基；~ 表示不重要连接。

**缩写可直接写进 STRUCT 的 SMILES**（渲染器支持，无需展开）：`[STRUCT:Ph-OH]`、`[STRUCT:AcOH]`、`[STRUCT:EtBr]`；后缀写法也放行（`-OH`、`COOH`、`-CHO`、`-NH2`）。画通用反应时优先用缩写。

### 5. 共振与电荷用 Lewis 式或部分电荷

讨论共振、共轭、极化时用 `mode=lewis`（含孤对与形式电荷）或 STRUCT 的 `charge=` 参数（δ±）。共振式中 σ 键骨架与原子核位置不动，只移动 π 键和孤对电子。

## 三、错误示范与避坑

1. **饱和碳原子上画弯箭头起点**——碳无孤对，不能作电子供体起点
2. **反应机理中省略关键孤对电子**——OH⁻ 进攻时需显示孤对，否则箭头起点悬空
3. **断裂的键不画出**——讨论 C–H 氧化时只画 CH₃ 而不显示参与键
4. **过度完整或过度简化**——复杂分子全展开干扰重点；反应中心过度简化使机理箭头无法定位
5. **共振式中原子核移动**——共振只是电子画法变化
6. **编号与上下标交给渲染器**——不要自己写 $、Unicode 上标或 <sub> 标签；label 直接写 CH3Cl、H2SO4 即可，渲染器自动排版

## 四、总结

- 简单分子 → 结构简式或文字；复杂骨架 → 键线式
- 反应机理 → 关键位点用 Lewis 式或完整结构式示出孤对与参与键
- 非反应部分 → R/Ar/X/波浪线省略
- 核心原则：让结构式替你把"故事"讲清楚，而不是被符号束缚
