# 结构式及其变体的使用规范

有机化学结构表示法的核心原则：**表示法服务于想表达的内容**，不要为画结构而画结构。

---

## 一、结构表示法的选择

| 表示法 | 适用场景 | 示例 |
| :--- | :--- | :--- |
| **结构式（展开式）** | 需要看清每一个原子和价键，尤其讨论反应位点周围环境时 | H–C–H 四键图 |
| **结构简式** | 快速表示分子组成与官能团，适合简单有机物 | CH₃Cl、CH₃CH₂OH、(CH₃)₂CHOH |
| **键线式** | 展示碳骨架和官能团，是最通用的专业语言；每个端点/折点默认是碳 | 苯环、环己烷 |
| **Lewis 结构式** | 需要展示孤对电子、形式电荷、电子来源时 | 水、氢氧根、碳负离子 |
| **楔形式 / Fischer / Newman** | 需要表达立体化学、构象、手性时 | (R)-乳酸、环己烷椅式 |
| **基团缩写 / 波浪线** | 聚焦核心反应位点，省略非反应部分 | R–X、Ar–CHO、~COOH |

---

## 二、什么时候用什么：简明规则

### 1. 简单有机物不必用键线式

- 对于 **CH₃Cl、CH₃OH、CH₃COOH** 等简单小分子，直接写结构简式或文字描述即可，不必强行画键线式。
- 键线式用于突出碳骨架、环系、多官能团结构等较复杂的分子。

**示例：**
- CH₃Cl → 写「氯甲烷（CH₃Cl）」或 `[STRUCT:CCl]`（一个碳加一个氯）即可，无需复杂骨架。
- 苯 → 适合用键线式 `[STRUCT:c1ccccc1]`。

### 2. 反应机理中必须示出参与电子转移的孤对电子

- 当反应涉及 **亲核试剂进攻、酸碱质子转移、碳负离子、烯醇负离子、羰基氧** 等时，相关的孤对电子必须像 Lewis 结构式一样示出。
- 原因：机理箭头的起点必须清晰可见，LLM 和渲染器才能正确画出电子来源。

**示例：**
- OH⁻ 进攻 CH₃Cl 时，OH⁻ 上的孤对电子必须显示，因为它是电子供体起点。
- 羰基氧参与共振或亲核进攻时，羰基氧上的孤对电子必须显示。

### 3. 反应位点必须突出强调

- 如果某根键参与反应（断裂、形成、极化），这根键必须画出来，不能省略或用缩写掩盖。
- 如果某个原子是反应中心，必须让其在结构式中清晰可见。

**示例：**
- 涉及 **C–H 键断裂**（如氧化、卤代、消除）时，必须把那根 C–H 键画出，并在其附近标注或画弯箭头。
- 涉及 **C=O 双键极化** 时，必须完整画出 C=O 双键，而不仅仅是写 R–CHO。
- 涉及 **苄位/烯丙位反应** 时，可以用键线式画出反应中心，而非只用 Ph–CH₂– 文字。

### 4. 聚焦关键位点，省略非反应部分

- 当分子很大、反应只发生在局部时，用 **R、Ar、X** 等缩写或 **波浪线 ~** 表示未参与反应的其余部分。
- 不要把无关的完整骨架全部画出，干扰重点。

**常用缩写：**
- R：烷基
- Ar：芳基
- X：卤素
- Me：甲基，Et：乙基，Ph：苯基，Ac：乙酰基，Ts：对甲苯磺酰基，Boc：叔丁氧羰基
- ~：表示与分子其余部分相连的不重要结构

**示例：**
- 讨论羰基 α-氢的酸性时，可以画 `[CH3-CO-CH2-]⁻` 或简化成 `~CO-CH₂⁻`。

### 5. 共振与电荷：必要时用 Lewis 式或部分电荷

- 讨论共振、共轭、极化时，优先使用 **Lewis 结构式**（含孤对电子和形式电荷）或 **部分电荷 δ+/δ-**。
- 共振式中，**σ 键骨架和原子核位置不动**，只移动 π 键和孤对电子。

## 三、结构式与标记的对应关系

| 你想表达的信息 | 推荐标记 | 关键要求 |
| :--- | :--- | :--- |
| 分子骨架、官能团 | `[STRUCT]` | 复杂分子用键线式；简单分子可省略 |
| 孤对电子、形式电荷、电子来源 | `[LEWIS]` | 必须显示所有价电子和孤对电子 |
| 反应机理中的电子转移 | `[MECH]` / `[REACTIONMECH]` | 涉及孤对电子时，先用 `[LEWIS]` 示出 |
| 极性键、部分电荷偏移 | `[CHARGE]` | 在反应位点附近标注 δ+/δ- |
| 共振极限式 | `[RESONANCE]` | 骨架不动，只移动 π 键和孤对电子 |
| 手性、构型 | `[STEREO]` | SMILES 含 @/@@ |
| 构象分析 | `[NEWMAN]` | 指定二面角 |

---

## 四、错误示范与避坑

1. **饱和碳原子上画弯箭头起点**：碳原子本身没有孤对电子时，不能作为电子供体起点。起点必须是孤对电子、π 键或 σ 键。
2. **反应机理中省略关键孤对电子**：如 OH⁻ 进攻时，不显示 OH⁻ 上的孤对电子，导致箭头起点悬空。
3. **断裂的键不画出**：如讨论 C–H 键氧化时，只画 CH₃ 而不显示那根参与反应的 C–H 键。
4. **过度完整或过度简化**：复杂分子全部展开会干扰重点；反应中心过度简化又会导致机理箭头无法定位。
5. **共振式中原子核移动**：共振只是电子画法变化，σ 键骨架和原子位置必须保持一致。

---

## 五、总结：形为意用

- **简单分子** → 结构简式或文字。
- **复杂骨架** → 键线式。
- **反应机理** → 关键位点用 Lewis 式或完整结构式示出孤对电子和参与键。
- **非反应部分** → 用 R/Ar/X/波浪线省略。
- **核心原则**：让结构式替你把“故事”讲清楚，而不是被符号束缚。
