# 孤对电子与电荷标注规范

本规范约定 Lewis 结构式与机理图中孤对电子点（pair）与形式电荷的标注方式。
渲染器已按本规范自动绘制；你（LLM）只需理解规则，确保在文字讲解中与图示一致。

---

## 一、术语定义

- **阻碍物（block）**：待标注原子周围与之**直接**相连的化学键和原子。
  block 的方向归入**上、下、左、右**四个方位；倾斜绘制的化学键归入左或右方向。
- **孤对电子（pair）**：待标注原子上的孤对电子对。

**核心原则**：孤对电子点尽量与其他阻碍物分离；无特殊说明时，孤对电子点标注在正上、下、左、右四个方向。

---

## 二、孤对电子摆放规则（按 pair 数与 block 数分派）

| pair | block | 规则 | 示例 |
|:---:|:---:|---|---|
| 3 | 1 | 按 block 方位分离 | block 在左侧 → pair 分布在上、右、下三处 |
| 2 | 2 | 同上方分离；**特例**：block 为左右两根倾斜键且同朝上（如水分子），pair 分布在左下和右下、分别张开 45°（若两键同朝下，同理放在左上和右上） | 水：两 O–H 键朝左上/右上 → pair 在左下(225°)、右下(315°) |
| 2 | 1 | 三者夹角 ≈120°（三角对称），pair 允许标注在 30° 的整数倍位置（水平向右为 0°） | block 在 180° → pair 在 60° 和 300° |
| 1 | 3 | 标注在正上下左右方向，遵循尽量分离原则 | 氨 N：三根 N–H 键占右/左/下 → pair 在正上方 |
| 1 | 2 | 类似 pair=2/block=1，pair 允许标注在 30° 的整数倍位置 | block 在 150° 和 270° → pair 在 30° |
| 1 | 1 | pair 位于 block 正对的一侧 | block 在左侧 → pair 在右侧 |

- 以上未列出的组合（如 pair=4、block=0 的卤素离子），遵循核心原则：正上下左右、尽量分离。

---

## 三、电荷标注规则

- 电荷标注在原子的**右上角**（45° 方向），且**不与孤对电子重叠**（可适当远离）。
- **例外**：若原子右侧有标签氢阻碍（如 OH⁻ 中 H 写在 O 右侧）且左侧无阻碍，
  电荷圈改标在**左上角**（135°）；左右两侧都有阻碍时仍标在右上角。
- **电荷外加圆圈**（⊕ / ⊝ 样式，半尺寸），主标签（元素符号与氢计数）中不再内嵌上标电荷。
- 书写 SMILES 时你仍按原样提供（如 `[OH-]`、`[Cl-]`），渲染器自动拆分主标签与圆圈电荷。

---

## 四、常见示例对照

| 分子/离子 | pair/block | 标注 |
|---|---|---|
| 水 H₂O（Lewis） | 2 / 2（特例） | 两对电子在 O 的左下、右下张开 45° |
| 氨 NH₃（Lewis） | 1 / 3 | 一对电子在 N 正上方 |
| 氢氧根 OH⁻ | 3 / 1（H 在右） | 三对电子在上、左、下；Θ 在右上 |
| 氯离子 Cl⁻ | 4 / 0 | 四对电子在正上下左右；Θ 在右上 |
| 甲基负离子 CH₃⁻ | 1 / 1 | 一对电子在与 CH₃ 相对的另一侧；Θ 在右上 |

## 五、键线式中的孤对电子：默认不标

在键线式中，孤对电子遵循"**默认不标、简洁至上**"的原则。渲染器在静态键线式
（如带 [XH]/[BOND]/[HBOND] 标注的分子）与普通反应方程式中一律**不画**孤对
电子点；仅在机理场景（有弯箭头引用）与共振场景（孤对电子参与共轭）中自动
画出。以下四种情况必须标出（此时渲染器已自动处理，文字讲解需与图示一致）：

1. **作为反应位点参与机理时**（为弯曲箭头提供起点，如 SN2 中 OH⁻ 进攻）；
2. **中心原子上带有形式电荷时**（如氧鎓离子或氮负离子，用以验证八隅律，
   此时电荷标注在原子右上角，且不与孤对电子重叠，建议电荷外加圈）；
3. **孤对电子参与共轭或影响芳香性时**（如吡咯、吡啶或卡宾等富/缺电子体系）；
4. **形成配位键或路易斯酸碱加合物时**（如硼烷络合物）。

与之相对，普通醇、醚、胺及末端卤素的孤对电子在常规静态结构中一律无需画出。
若确需标注，务必置于原子外侧以避免与骨架线重叠，并严格区别于单电子自由基点
（一个点）。
